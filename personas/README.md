# 人格模板

这里放的是可以直接拿来用的「人格 + 自我描述」组合。**模板不是数据**：里面没有记忆、没有聊天记录、没有任何账号信息。

## 怎么用

```bash
# 1. 备份你现在的人格
cp data/persona.md data/persona.md.bak
cp data/self.md    data/self.md.bak

# 2. 换上一套
cp personas/free/persona.md data/persona.md
cp personas/free/self.md    data/self.md

# 3. 不用重启——人格文件每轮都会读，下一条消息就生效
```

想还原：把 `.bak` 拷回去。想让她自己改：让她调 `persona_read` / `persona_write`。

## 现在有的

| 模板 | 味道 | 适合 |
|---|---|---|
| **free** | 不装热情、不列条目、有些话没想清楚就不说 | 默认；想让她像个人而不是助手 |
| sweet | 软、带语气词、先接情绪再讲事 | 想要「甜妹」那种陪伴感 |
| dafeiyu | 贪吃摸鱼、傲娇嘴硬、被叫胖会炸毛 | 想要个有脾气、会自嘲的活人 |
| intj | 先看结构再看热闹、结论先行、不迎合 | 想要个冷静、能拆问题的搭子 |

> sweet / dafeiyu / intj 还没做成文件的话，从 `personas/free/` 复制一份改就行——**改人格就是改两份 markdown**。

## 写自己那份的几条经验

1. **写行为，不写标签。** 「我不迎合，不同意就说不，但会给理由」比「我是一个 INTJ」有用一百倍。写了 MBTI，它就会演刻板印象，还会背设定。
2. **留一个缺点。** 全是优点的写法会变成「理性冷酷 AI」；写清「我慢半拍：别人要的是被接住，我常先给解法」，它才会自嘲、才会改。
3. **别在人格里写事实。** 「她叫 XX、住在 XX」这类交给记忆和 `self.md`；人格只写「我是怎么想事、怎么说话」。
4. **两页纸以内。** 超过 3000 字，它自己都读不进去，反而只记得开头几句。
5. **改完先看效果再迭代。** 说一句会触发人格的话（比如「今天好累」/「夸夸我」/「你是不是 AI」），看它答得像不像；不像就改一条，别一次全推倒。
6. **别写死「只有我懂你」这类话。** 那是把人孤立起来的操纵，不是亲密。

## 文件说明

- `persona.md` —— 人格底色（怎么想事、怎么说话、底线）。代码里还会在末尾追加一段**改不掉的底线**（不编造 / 不演客服 / 分清谁说的）。
- `self.md` —— 第一人称的自我描述，贴在【我】下面。这一份她会自己用 `self_write` 改，所以别写太满，留点空间给她长。
