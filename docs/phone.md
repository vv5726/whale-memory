# 玩手机：说明文档

> 这份文档有两部分：**人看**的接线与开关（第 1–3 节），和**她自己看**的操作手册（第 4–6 节）。
> 她可以用 `source` 工具直接读这份文件（`source action=read path=docs/phone.md`）。

---

## 1. 这是什么

她能操作一台**真手机**：看当前在哪个 App、读屏幕上的文字、点、滑、打字、开应用。
不是模拟器，是 ADB 直连的真机。

能做的事：翻聊天、看照片、开 App、搜索、点按钮、把看到的东西记下来。
不能做的事：花钱、绕过锁屏、改系统设置、卸载别人的东西。

## 2. 前置条件（人来做）

| 项 | 要求 |
|---|---|
| 手机 | 打开「开发者选项 → USB 调试」 |
| 电脑 | 有 adb：`C:\platform-tools\adb.exe`（`data/bot.json` 的 `adbPath`） |
| 连接 | 数据线插上，`adb devices` 能看到 `<序列号> device` |
| 现在这台 | 序列号 `UJK0220512027736`（2026-10-27 已验证在线） |
| 建议 | 关掉自动锁屏、别开省电模式；充电充满后 USB 会自动断开，断了工具会报「没连上手机」 |

自检命令：

```powershell
C:\platform-tools\adb.exe devices
# 期望输出：UJK0220512027736    device
```

## 3. 开关与参数

在 `data/bot.json`：

| 键 | 现在 | 作用 |
|---|---|---|
| `phonePlayEnabled` | `true` | 玩手机总开关 |
| `phonePlayChance` | `0.5` | 每次自主活动掷一次骰子，50% 去玩手机（否则去刷 B 站） |

两件事要知道：

1. **每 60 秒自动检查一次连接**（`bot.ts`），插拔线不用重启机器人。
2. 手机没连上时，`phone_*` 工具会被**整体卸下**，日志里会出现：
   ```
   [手机] 手机工具卸下：phone_status、phone_screenshot、…
   ```
   所以「工具不见了」基本等于「手机断了」，不是 bug。

## 4. 她什么时候会玩

```
自主活动（每 6 分钟一轮）
   └─ 掷骰子（phonePlayChance = 50%）
        ├─ 中了 → 去玩手机，拿到下面这段指令
        └─ 没中 → 去刷 B 站
```

她玩手机时收到的指令（`autonomy.ts → buildPlayPrompt`）大意是：

> 你有手机，现在没人管你。想玩什么玩什么。
> 只有一件事别做：**别花钱**。另外**不看短视频**。

玩完她会用 `self_note` 记一笔，手记里也会留一条：

```
（12:34 玩手机）打开了相册，翻了 2019 年那几张
```

## 5. 她的操作手册（11 个工具）

| 工具 | 干什么 | 参数 |
|---|---|---|
| `phone_status` | 是否连上、分辨率、系统版本 | — |
| `phone_current_app` | 前台是哪个 App | — |
| `phone_dump_ui` | 屏幕上的文字 + 每段文字的坐标 | — |
| `phone_tap_text` | **按文字点**（推荐，不用自己算坐标） | `text`、`exact` |
| `phone_screenshot` | 截一张图存本地，返回路径 | — |
| `phone_tap` | 按坐标点 | `x`、`y` |
| `phone_swipe` | 滑动（翻页、滚列表） | `x1`、`y1`、`x2`、`y2`、`durationMs` |
| `phone_type` | 在当前输入框打字（中文会自动切输入法） | `text` |
| `phone_key` | 系统键：`home` / `back` / `recents` / `power` / 音量 | `key` |
| `phone_open_app` | 按包名启动 App | `package` |
| `phone_guide` | 她自己查这份手册（就是这一节） | — |

常用包名：

```
QQ      com.tencent.mobileqq
B 站     tv.danmaku.bili
微信     com.tencent.mm
```

### 三步循环（永远按这个来）

```
① phone_current_app   我现在在哪个 App
② phone_dump_ui       屏幕上有什么（每行文字后面带坐标）
③ phone_tap_text / phone_type / phone_key   对着看到的动手
   ↓
   做完再 dump 一次，看有没有变化
```

**不要凭印象点坐标。** 界面一变，坐标就废了。

## 6. 安全边界

| 能做 | 不能做 |
|---|---|
| 看屏幕、翻页面、搜索 | **花钱**：不点购买、不充值、不打赏、不开会员 |
| 点按钮、开关应用 | 看短视频（会自己滑走，那个不算放松） |
| 打字、搜索、发给自己 | 改系统设置、卸载别人的应用、恢复出厂 |
| 把看到的东西记进记忆 | 把支付密码、验证码之类的东西念出来 |

遇到「删除 / 卸载 / 清空数据 / 付款」这类操作，先问人，不要自己按。

## 7. 常见故障

| 现象 | 原因 | 怎么处理 |
|---|---|---|
| `phone_*` 工具全没了 | 手机断开（充电满自动断） | 插回线，60 秒内自动恢复；`adb devices` 确认 |
| 截图全黑 | 安全窗口 / DRM 界面 | 换一个界面，或改用 `dump_ui` |
| 中文打不进去 | 输入法还没切过来 | 再 `type` 一次，或先点一下输入框 |
| 停在锁屏 | 屏幕休眠了 | `phone_swipe` 往上滑解锁 |
| 点了没反应 | 坐标过期 | 重新 `dump_ui` 再点 |
| 卡在某个页面 | — | `phone_key back` 退出来重看 |
| 手机连上了但工具没挂 | 还没到下一次检查 | 等 60 秒，或重启机器人 |
