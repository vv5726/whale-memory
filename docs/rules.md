# 第四部分：我看到的问题（待你定）

## 1. 弱记忆守卫的误伤风险还在

第 1 条拦截依赖「有没有问往事」的判断。这个判断是正则，靠不住。今天已经误伤过两次：
- 「我希望你说话短一点」被当成提问 → 已修（陈述句不算）
- 「你看懂这句话了吗」被当成问往事 → 已修（对话本身豁免）

**还可能误伤**：比如「这也太离谱了吧」含「吧」不触发；但「你在想什么呢」会被当成提问。要不要我把判定再收窄，只认「记得/那次/上次/以前/多久」这几个明确的词？

## 2. 「短，一到三句」和「分气泡」有点冲突

拆气泡是按句号拆的。如果它只写一句，就不拆；写三句就拆成三条。现在效果还行，但如果你想让它话多一些，这条得松。

## 3. 共享记忆的锚点真会串

第 7 条加权只是「优先」，不是「隔离」。如果朋友和你都聊过「妈妈」，检索到朋友的妈妈的**可能性降低了但没有归零**。要彻底分开得给锚点也加 speaker——工程量不小。

## 4. 走神挑锚点的随机性

现在是纯随机 + 排除最近 12 小时想过的。这意味着**重要的锚点不会优先被想起**。要不要改成按权重/情绪强度加权？

## 5. 睡眠的三个触发条件有点乱

3 分钟、12 小时、每天 4 点——三个都可能触发，且 4 点那次会重读整天。如果你发现日志里睡眠太频繁，我把 12 小时那条删掉。
