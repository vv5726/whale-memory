# 「凝」技术规格（术语与概念）

> 版本 1.0 ｜ 2026-10-27 ｜ 参照同类项目的术语体例写成，便于横向比较
>
> **本文区分「机制」（可计算、可验证）与「隐喻」（借用命名但没有对应实质）。** 不主张系统具有意识或主观体验。

---

## 摘要

「凝」是一个跑在 QQ 上的陪伴型机器人，核心是**预算驱动的分层记忆 + 锚点关系网 + 走神**。
它不追求「什么都记住」，而是像人一样：记得越快想起来的越清楚，久远的只剩感受和地址。

全部实现**零依赖**：Node 24 直接跑 TypeScript，存储是单个 SQLite 文件（`node:sqlite`），
没有向量库、没有 ORM、没有分词库。

---

## 1 分层架构

| 层 | 术语 | 实现 | 载体 |
|---|---|---|---|
| **L0** | 自我图式 | 人格 + 底线 + 自我描述 + 说话规矩（**全量注入，无检索**） | `data/persona.md` `self.md` `speech-rules.md` + 代码里的 `PERSONA_FLOOR` |
| **L1** | 工作记忆 | 原始对话（`turns`）+ 内存历史（存 50 条，送 30 条） | SQLite `turns` |
| **L2** | 长时记忆 | 事件三层 + 锚点图 + 冷存储 | `events` / `anchors` / `edges` / `cold_archive` |
| **L3** | 动机 | **走神**：随机锚点 → 四问 → 四途径 | `autonomy.ts` + `intent.ts` + `data/think-prompt.md` |
| **L4** | 具身 | **无**。只有 ADB 手机作为「外部的手」 | `tools/phone.ts` |
| **L5** | 服务与调度 | 睡眠（整理）、定时器、计划表、额度 | `sleep.ts` / `bot.ts` / `quota.ts` / `cost.ts` |

**和同类系统的最大差别**：L0 是纯文本全量注入，没有索引（详见 §9 已知缺陷 1）。

## 2 记忆子系统

### 2.1 分类

两类正交标签：

**事件类别 `events.kind`**（借 sage-mem 的分法）：`event` 发生过的事 / `user` 你是谁 / `feedback` 该怎么做事 / `project` 项目状态 / `reference` 外部指针。

**锚点类别 `anchors.kind`**：`person` 人 / `place` 地点 / `scene` 场景 / `event` 事 / `theme` 话题 / `legacy` 早期未分类 / `merged` 合并后的节点。

现状：2,399 条事件；521 个锚点（event 430 / legacy 64 / person 12 / merged 10 / place 3 / scene 2）。

### 2.2 编码（对话 → 事）

- **抽取**：LLM 优先（v3 事件卡：`etype` / `status` / `evidence` / `memory_value` 等），失败自动回落启发式；结果落库即冻结，重跑不重抽。
- **关键事实穿透**：金额、日期、结论单独存 `key_facts`，**任何一层都不许压掉**（现 926 条带关键事实）。
- **时间归一化**：存绝对时间戳 + `period_label`（「2024年夏天（2年前）」），渲染时按「今天 / 昨天 / N 天前」说人话。
- **说话人**：`speaker_id`（现 1,392 条有值）。共享记忆下用来区分「你妈」和「朋友的妈」。

### 2.3 存储

```
events ──event_anchors(role)──> anchors ──edges(relation,weight)──> anchors
   │                                    
   └─ archived=1 的下沉 / 丢正文前先写 cold_archive（原文 + cold:// 地址）
```

| 表 | 现状 | 说明 |
|---|---|---|
| `events` | 2,399 | 事件卡（三层之一） |
| `anchors` | 521 | 锚点（人/地/场景/事/话题） |
| `edges` | 16,052 | same-day 15,916 / co-occur 136 |
| `event_anchors` | 9,789 | mentioned 8,637 / speaker 1,147 / subject 5（**带角色**） |
| `anchor_aliases` | 109 | 别名归一（老王 / 王哥 / 建国 → 王建国） |
| `cold_archive` | 1,600 条 / 167,123 字 | 底片，只给地址 |
| `turns` | 3,029 | 原始对话 |

**没有向量通道。** 字面召回用 bigram + IDF + FTS5 trigram。

### 2.4 三层与下沉（预算驱动，单向）

| 层 | 留下什么 | 预算 | 现状 |
|---|---|---|---|
| `detailed` | 标题 + 正文 + 因果 + 关键事实 | 预算 × 30% | 809 条 / 95,331 token |
| `compressed` | 丢正文，留起因 + 结果 + 片段 | 预算 × 50% | 1,590 条 / 83,367 token |
| `fossil` | 只剩感受 + 一个片段（`archived=1`） | **不占 token，按条数封顶 100 万** | 0 条 |
| `cold_archive` | 原文全文 | 磁盘 | 1,600 条 |

`contextBudgetTokens` = 1,000,000。下沉**从最旧、最弱的开始，只往旧的方向走**，不会因体积波动来回升降。

### 2.5 召回打分

```
证据 = 锚点激活 × 边权重（求和）
     + 情景连带（强证据 ×0.35，同人同 120 天内）
     + 字面命中（IDF 加权的二字组）
     + FTS 命中（+0.6）

raw   = (证据 + 情绪加成 + 新鲜度加成) × 同人系数 × 质量分 × 标题命中
总分  = (raw × 层可及性 + 钉住加成) × (1 + 0.25 × (strength − 1))
```

| 项 | 值 | 说明 |
|---|---|---|
| 激活扩散 | 最多 2 跳，衰减 `[1.0, 0.5, 0.25]` | 图上的传播 |
| 惰性展开 | 只取激活 top 6（放宽 12），门槛 0.15 | 防一次拉一大片 |
| 情绪加成 | 0.35 × arousal | 只加分，不凭空顶上无关旧事 |
| 新鲜度 | 30 天半衰 ×0.1 | 钉住的 / 带关键事实的**不衰减** |
| 同人系数 | 自己的事 ×1.25 / 别人 ×0.75 | 共享记忆下防串味 |
| 标题命中 | ×2.6 | 区分「在讲这件事」和「顺带提到」 |
| 层可及性 | 1.0 / 0.75 / 0.35 | 越旧越难自己浮现 |
| 钉住加成 | 0.6 × clamp(证据,0,1) | 钉住是「想起来更牢」，不是「永远置顶」 |
| 相关性闸门 | `证据 ≥ min(0.25, max(0.06, 最高分×0.3))` | **看证据不看总分** |
| 情绪采样 | 池 8 条，温度 `0.6 + 1.2×arousal` | 越激动越随机 |
| 注入上限 | **1,200 token**，单条 ≤180 字 | 超了从最低分丢 |

### 2.6 遗忘

| 对象 | 半衰 | 备注 |
|---|---|---|
| 记忆新鲜度 | 30 天 | 钉住 / 关键事实不衰 |
| 情绪（心境） | 10 小时 | 淡到很浅归「平静」 |
| 锚点显著度 | 每次睡眠 ×0.98 | —— |
| 边 | **热 15 天 / 温 3 天 / 冷 2 天** | 按两端锚点挂的记忆在哪一层决定 |
| 边上限 | 温 2 万 / 冷 2 千 → 砍到 50% | 热边不设上限；热转温那批只留 25% |

### 2.7 钉住（三道闸）

| 参数 | 值 | 含义 |
|---|---|---|
| `pinnedLimit` | 50 | 全库最多钉几条（现 104，已超） |
| `pinnedDailyLimit` | 3 | 每天最多新钉几条 |
| `pinnedTtlDays` | 400 | 普通钉住的有效期 |
| 永久钉住 | 密码 / 手机号 / 生日 / 最喜欢 / 不喜欢 | 不设有效期 |

### 2.8 情绪

- 每条记忆带 `valence` / `arousal` / `tags` / `summary`（模型给优先，词典兜底）
- **双轨**：`affect`（当时）与 `felt_now`（现在想起来）= `0.6×当时 + 0.15×心境`，同一件事最多一小时刷一次
- 心境 `mood_state`：10 小时半衰，睡眠时按最近 7 条重算。现状：平静（v 0.04 / a 0.37）

### 2.9 人物图

`people`（8 人）+ `anchor_aliases`（109 条）。同一件事三种角色：谁说的（speaker）、说的是谁（subject）、提到谁（mentioned）。

## 3 自主：走神

### 3.1 触发与闸门

| 闸 | 值 |
|---|---|
| 开关 | `thinkEnabled` |
| 间隔 | 1.5–3.5 分钟**随机**（不做节拍器） |
| 你没说话 | 安静 ≥ `thinkIdleSeconds` 30 秒 |
| 刚干完活 | 缓 `thinkSettleSeconds` 90 秒 |
| 时段 | `autonomyHours` |
| 掷骰子 | `thinkChance` 85%（纯本地随机，不花钱） |

### 3.2 四问 → 四途径

提示词里让她自己回答：**目的 / 途径 / 消息 / 给谁**。途径只有四种，每种都有执行器：

| 途径 | 执行 | 轮数上限 |
|---|---|---|
| 聊天 | `onSpeak(msg, to)` → 真发出去 | — |
| 内容 | 派阅读员看一轮 B 站 → 简报 → 存知识库 | 6 + 4 |
| 做 | 给一件事，真的动手 | 3 |
| 算了 | 什么都不做 | — |

走神和它派生的动作**都不碰手机**（手机工具只在聊天里可用）。

### 3.3 停用项

| 机制 | 状态 |
|---|---|
| 自主活动（每 6 分钟一轮，看 B 站 / 玩手机） | **定时器已关**（`autonomyEnabled: false`），主体已并入「内容」途径 |
| 主动开口（闲置 45 分钟定时问候） | **停用**（`startSpeaking()` 第一行返回） |

## 4 表达与提示词

### 4.1 结构（一次请求里）

```
人格 + 改不掉的底线 + 【我】(self.md) + 额度 + 【今天】
+ 计划表 + 【记忆】(≤1200 token) + 工具清单(74) + 谁是谁
+ 场景 + 【他这句话】(读心) + 近 30 条历史 + 当前这句
+ 说话规矩（追加在最后）
```

### 4.2 关键数字

| 项 | 值 |
|---|---|
| 历史 | 库里留 50 条，送 30 条 |
| 记忆块 | ≤1,200 token，单条 ≤180 字 |
| 工具定义 | 74 个 / 25,454 字符（每次请求全量重发） |
| 工具环 | 跑到模型不再要工具为止，硬顶 999 轮；单次超时 90 秒 |
| 去重 | 同一条 `message_id` 90 秒只认一次 |

## 6 事实纪律（三道闸）

1. **提示词底线**：数字、日期、结论以〔事实：…〕为准；记不清就问，不猜。
2. **数字守卫**：问往事时，回答里的具体数字必须能在记忆里找到（`1万` 与 `一万` 归一化后比较），否则换成「不记得了 / 哪次？」。
3. **不认领引用**：对方复述「你说过…」时先核对，「哦那句是我说的」比「我不确定」危险得多。

## 7 运行与成本

| 项 | 值 |
|---|---|
| 模型 | `deepseek-chat`（可切本地 Ollama `qwen3:8b`） |
| 上下文窗口 | 1,048,576 |
| 睡眠触发 | 聊完 3 分钟 / 攒够 50 条 / 闲置 12 小时 / 每天 3–5 点 |
| 每日上限 | ¥50（超了当天不再调模型） |
| 单价 | 输入 ¥0.5/M（缓存命中按 1/10）、输出 ¥8/M |
| 今天实测 | 310 次调用 / 输入 10,379,335 / 输出 69,964 token / ¥5.75（缓存后 ¥2.79） |
| 平均每次调用 | ≈ 33,000 输入 token |

**成本结构**：工具环每轮重发全量提示词，所以「轮数」是平方级花钱；掷骰子那一步纯本地，不花钱。

## 9 效度声明（明确「没有」什么）

| 说法 | 事实 |
|---|---|
| 「她有情绪」 | 是 `valence`/`arousal` 两个数 + 半衰公式 + 模板渲染，**不是主观体验** |
| 「她记得」 | 是压力下推的分层存储，第 1,200 token 之后的东西她根本看不见 |
| 「她会想」 | 是随机取一个锚点、拼提示词、调模型；**没有内部状态机，也没有规划器** |
| 「她主动」 | 是掷骰子 + 走神；定时主动开口已停用，自主活动定时器已关 |
| 「她的数字能力」 | 数字守卫只拦「问往事」时的编造，**她仍会算错** |
| 向量 / 语义检索 | **没有**。只有锚点图 + bigram + FTS |
| 具身 / 空间 | **没有**。没有房间、没有坐标、没有天气 |
| 动机模型 | **没有**。走神不做「驱力积分」，只做「想起什么」 |

## 10 已知缺陷

1. **L0 没有索引**：人格 2,227 字 / 36 条规矩全量注入，加一条就稀释其它条（改进思路见 `plan-prompt-layers.md`）。
2. **同一条 `turn` 的时间戳是当天中午**（`dayKeyToTs`），所以「多久没说话」不能从库里查，只能看手记。
3. **一部分旋钮没接线**：`groupSpeakThreshold`、`silentCheckMinutes`、`autonomyIdleMinutes` 存了但不生效。
4. **`budget.requestsLeft` 不存在**：自主活动的额度闸门永远为假（`undefined <= 0`），提示词里会写出「还能调 undefined 次模型」。
5. **走神被自己的循环堵**：`thinkSettleSeconds` 90 秒 vs 自主活动每 6 分钟，实测 12 次走神里 5 次被「刚忙完」挡掉。
6. **她会宣称做完了但没落地**：卡榫规则写进了知识库，而没写进每次注入的 `speech-rules.md`。

## 11 术语对照

| 中文 | English | 本系统含义 |
|---|---|---|
| 分层记忆 | tiered memory | detailed / compressed / fossil 三层，预算驱动单向降级 |
| 锚点 | anchor | 记忆的索引节点：人 / 地 / 场景 / 事 / 话题 |
| 激活扩散 | spreading activation | 沿锚点边传播（2 跳，衰减 1 / 0.5 / 0.25） |
| 冷存储 | cold archive | 原文永久留存，上下文里只给 `cold://` 地址 |
| 钉住 | pin | 防下沉 + 检索加权，有总量/每日/有效期三道闸 |
| 当时 / 现在 | at-the-time / felt-now | 情绪双轨：事件当时的感受 vs 现在想起来 |
| 心境 | mood | 全局情绪状态，10 小时半衰 |
| 睡眠 | sleep | 一次可中断、可重跑的批处理：抽取→绑定→压缩→衰减→心境 |
| 走神 | mind-wandering | 随机锚点 → 四问 → 四途径（聊天/内容/做/算了） |
| 途径 | channel | 走神的出口；只有「聊天」会真的发消息 |
| 阅读员 | reader agent | 只读 B 站的子代理，只交回几百字简报 |
| 底线 | floor | 代码里那段改不掉的：不编造、不演客服、分清谁说的 |
